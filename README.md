# REDES DE COMPUTADORES I — TRABALHO DE SOCKETS

Aplicação remota desenvolvida para a disciplina de **Redes de Computadores I**, utilizando conceitos de programação com sockets, comunicação cliente-servidor e troca de mensagens entre dispositivos distintos.

## Sobre o Projeto

Este projeto foi desenvolvido como parte da atividade prática proposta na disciplina, cujo objetivo é implementar uma aplicação remota utilizando sockets, contendo:

- Implementação de cliente e servidor
- Comunicação remota entre dispositivos diferentes
- Uso de protocolos de rede
- Execução prática em ambiente real

A proposta do trabalho exige que a comunicação ocorra remotamente, não sendo permitido o uso de loopback (`localhost`) no mesmo dispositivo.
